Why Pyroshape

Keep the backend small enough to follow from request to response. Core handles authentication, PDO, logging, and JSON errors. Your app owns its routes, rules, and data.

Slim
Slim routes requests and runs middleware. Add a route or a request check where your app needs it.
PHP-DI
PHP-DI wires constructor dependencies. Test controllers and services with the dependencies you choose.
PHP-FIG / PSR
Standard interfaces connect HTTP messages (PSR-7), middleware (PSR-15), containers (PSR-11), and logging (PSR-3).

Stateless on ordinary requests

The browser sends one encrypted cookie containing two signed JWTs. A short-lived access token authenticates ordinary requests. A longer-lived refresh token can renew access after a database check.

›Request authenticated from the token

Core verifies the access JWT and reads its claims. With a valid access token, ordinary authentication skips the session lookup in the database.

User accounts come with Core

Register, verify an email address, sign in, check the session, change a password, and sign out through JSON endpoints. For sensitive actions, check current session status, permissions, and ownership in your app.

How to use Pyroshape

Add Core to a PHP app with Composer, or start with the SvelteKit starter and its sign-in flow.

Install with Composer

Run this in your app directory with PHP 8.5 or later.

Terminal
composer require tuxweb-it/pyroshape

Add a JSON endpoint

Extend the Core App class and register your Slim routes in setupAppRoutes(). Core registers those routes before the SPA fallback.

src/App.php
<?php

use Psr\Http\Message\ResponseInterface;
use Psr\Http\Message\ServerRequestInterface;
use TuxWeb\Pyroshape\Core\App as CoreApp;

final class App extends CoreApp
{
    protected function setupAppRoutes(): void
    {
        $this->getSlimApp()->get(
            '/api/ping',
            static function (
                ServerRequestInterface $request,
                ResponseInterface $response,
            ): ResponseInterface {
                $response->getBody()->write('{"ok":true}');
                return $response->withHeader(
                    'Content-Type', 'application/json'
                );
            },
        );
    }
}
